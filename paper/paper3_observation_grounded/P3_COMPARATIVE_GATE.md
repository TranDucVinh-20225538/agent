## Unit of n, locked now

A **comparison** is one `(task, model-pair)` under one locked construct:

* the same task specification,
* the same gold / component definition,
* the same observation protocol,
* the same frozen evaluator,
* the same pre-registered intervention.

Comparisons that **share a task** are one **cluster**. Three models on one task give
three raw pairs and **one** independent unit. Raw cells, raw pairs, and raw legs are
reported. They are not n.

**n = number of task-clusters** that each contain at least one pre-registered model-pair.

---

## Gate, locked before effect

The expansion **succeeds as a sample** only if the new corpus yields

> **n ≥ 20** task-clusters

with the construct above. Only after that gate passes may any ordering / inversion /
Δ statistic be computed.

This is not “run until a ranking flips.” It is “obtain a sample large enough that
existence can become a comparative empirical claim.”

If a designed cohort cannot be shown, **before the first new trajectory**, to reach
n ≥ 20 under this definition, the experiment is not started. The threshold is not
lowered after a shortfall. Path A is written instead.
